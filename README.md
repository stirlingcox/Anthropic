# Todo App with Drag & Drop

A modern, interactive todo application with drag-and-drop functionality across different work categories.

## Features

- **4 Work Categories**: Work, Personal, Urgent, and Completed
- **Drag & Drop**: Easily move tasks between categories by dragging
- **Add Tasks**: Quick task entry with category selection
- **Delete Tasks**: Remove completed or unwanted tasks
- **Local Storage**: Your tasks persist across browser sessions
- **Task Counters**: See how many tasks are in each category
- **Responsive Design**: Works on desktop and mobile devices

## How to Use

1. **Open the App**: Simply open `index.html` in your web browser
2. **Add a Task**:
   - Type your task in the input field
   - Select a category from the dropdown
   - Click "Add Task" or press Enter
3. **Move Tasks**:
   - Click and drag any task to a different category
   - The task will automatically update its category
4. **Delete Tasks**:
   - Click the "Delete" button on any task to remove it
5. **Track Progress**:
   - Watch the task counters update automatically
   - Move tasks to "Completed" when done

## Categories

- **💼 Work**: Professional tasks and projects
- **🏠 Personal**: Personal errands and activities
- **🔥 Urgent**: High-priority items needing immediate attention
- **✅ Completed**: Finished tasks

## Technical Details

- **Pure JavaScript**: No frameworks required
- **HTML5 Drag & Drop API**: Native browser functionality
- **Local Storage**: Automatic data persistence
- **CSS Grid**: Responsive layout
- **Modern CSS**: Gradient backgrounds and smooth animations

## Files

- `index.html` - Main HTML structure
- `styles.css` - All styling and responsive design
- `app.js` - JavaScript logic for drag-and-drop and task management

## Browser Compatibility

Works on all modern browsers that support:
- HTML5 Drag and Drop API
- Local Storage
- CSS Grid

Enjoy organizing your tasks!
